# Black Shark — To-do list

افتح `index.html` بالمتصفح مباشرة، أو باستخدام Live Server.
التطبيق لا يحتاج تنزيل مكتبات أو تشغيل backend.

- `index.html`: عناصر الصفحة والأزرار.
- `todo.css`: الألوان، المسافات، وترتيب الواجهة على الكمبيوتر والموبايل.
- `todo.js`: إضافة المهام، البحث، الفلاتر، التعديل، الحذف، وحفظ البيانات.

اكتب المهمة، اختر الأولوية، واضغط **Add**. لكل مهمة قائمة **Low / Medium / High** وزرا **Edit / Delete**. ضع علامة في المربع لإنهاء المهمة.

استخدم **All / Completed / Uncompleted** لتصفية القائمة. تظهر نتائج البحث مباشرة من أول حرف وتُحدّث مع الكتابة. زر **Search** وEnter يعملان أيضًا. امسح البحث لعرض القائمة مجددًا.

عند التعديل، **Save** أو Enter يحفظ، و**Cancel** أو Escape يلغي. المهام محفوظة في `localStorage` داخل نفس المتصفح؛ ليست مشتركة بين الأجهزة.

زر **Clear all** بجانب **Uncompleted** يمسح جميع المهام، بما فيها المخفية بالبحث أو الفلاتر، ويحفظ القائمة الفارغة.
